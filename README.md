2. Creadores:

3. Descripción
Aquí subimos tres programas hechos en C#:
- MiPrimeraGUI: Fue nomás para agarrarle la onda a Visual Studio haciendo un menú sencillito sin mucho propósito.
- MiPrimeraClase2: Una práctica donde fuimos viendo cómo usar clases y objetos en el código.
- ProyectoDesa3: El proyecto final donde unimos todo lo anterior y le conectamos una base de datos, para su correcta ejecución es necesaria la base de datos, pero esta misma no se encuentra disponible.

4. Configuraciones e Instrucciones
- Programa usado: Visual Studio Community (C#).
- Cómo abrirlos: 
  1. Descarga la carpeta.
  2. Abre el archivo .sln del proyecto que quieras checar.
  3. Dale en Iniciar para compilarlo.
  4. *Nota:* Para que el ProyectoDesa3 jale bien, ocupas tener la base de datos conectada.
